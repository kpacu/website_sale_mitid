Step-by-Step Configuration

1
Configure Your Signicat Broker

In your Signicat (or MitID OIDC broker) application dashboard, register your return callback URL:

https://your-domain.com/shop/mitid/callback
2
Set System Parameters in Odoo

Go to Settings → Technical → System Parameters and configure these 3 keys:

Parameter Key Description Example Value
mitid.broker_domain Your OIDC broker base URL https://your-tenant.sandbox.signicat.com/auth/open
mitid.client_id Your OIDC Client ID sandbox-short-sheep-673
mitid.client_secret Your OIDC Client Secret your_broker_secret_key
3
Assign eCommerce Alcohol Category

Under Website → eCommerce → Products, ensure all age-restricted products are assigned to a public category containing the word Alcohol (e.g. Alcohol, Beer & Alcohol, Wine & Spirits).
